    User/Group Commands
    User/group commands. useradd,mod, passwd groups
    useradd/userdel adduser/deluser very similar to each other
    adduser/deluser is easier to say than useradd.userdel. meaning that its easier to execute, interactive
    1. useradd
      • Uses useradd {option} {option_argument} {username}
      • options,
        • -c Adds a comment to the users account
        • -e Adds a expiration date for the user
        • -m Creates the users home Directory
        • -s Specifies the shell the user should use
        • -u Sets the users ID to specified
        • -D Displays the default settings, Doesnt require option_argument or username
    2. userdel
      • Removes a users account
      • USES userdel {username}
      • Options
        • -r Removes user and the Users Home Directory
    3. usermod
      • Modifies an existing account
      • USES usermod {options} {option argument} {username}
      • Options
        • -c Adds a comment to the users account
        • -e Adds an expiration date to the users account
        • -a Appends, adds to user
        • -g changes users primary/main group (only one)
        • -G adds user to a group as a supplementary/secondary
          without -a(append) it removes the user from all other supplementary groups
        • -aG Appends to a users supplementary/secondary groups
    4. groupadd
      • adds a group. thats all it does
        im not adding uses if thats all it does
    5. groupdel
      • all it does is Delete a group
    6. groupmod
      • Modifies an existing group
      • USES groupmod {options} {option arguments} {username}
      • Options
        • -n {newName} {oldName} Changes groups name
        • -g {GID} {Name} Changes a groups ID
    7. passwd
      • Changes the password of a users account
      • USES passwd {username}
      • Options
        • --expire Immeditaly expires a users passwd
        • -x Sets the max num of days a password will remain valid
        • -n Sets the min number of days a passwd remains valid
        • -w Num of days before a user with an expired passwd gets a warning
        • -S Displays users passwd status
    8. chage -l {username}
      • Shows info about a users passwd and account status
        passwd: last changed,inactivity,expires,how long till passwd change warning
        and account expire date


    Reading,writing / Manipulating Files
    Reading/writing to files
    1. cat
      • Displays the full contents of a file
    2. head & tail
      • Think of these as the cats body, cat displays the entire file
        its top(head) is the top 10, and its bottom(tail) is the bottom 10
      • head displays the first 10 lines of a file
      • tail displays the last 10 lines of a file
      • Options
        • -n Lets you choose the ammount to display
          tail -n 2 will display the last 2 , same logic with head with first 2
      • less
        • displays the first 10 lines, but also lets text based linux scroll up and down on the file
    3. touch & rm
      • touch creates a file While rm ReMoves a file
    4. chmod or Change Mode
      • Lets a user change the permissions/Mode of a file read, write, execute
      • When writing a script you need to enable execute so you can achually run the file
      • Read=4 Write=2 Execute=1
      • each step is multiplied by two so any combination of the numbers will only go to a specific modes

    cat Known as concatenate
    • Reads the entire contents of a file in one long "chain"
    • Can write to a file with >> ex cat "Hello World!" >> welcome.txt"
    head and tail, I call the Cats body
    • Cat displays the entire file, meaning its head displays the top 10 lines, and its tail is the last 10

    sudo Known as SuperUser Do
    • Typed in the beginning of a command
    • Runs a singular command with elevated permissions, or as root, if the permission is granted in sudoers
    • Uses sudo mkdir /usr/bin

    su Known as SuperUser
    • Switches your current user to specified
    • Uses su catmaster
    • Without statement, logs in as root
    • exit brings you back to your user
